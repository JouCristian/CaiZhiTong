## 1. 启动与认证

- 打开 `http://127.0.0.1:5173`，使用本地 `.env` 中的 admin / lab / student 凭据。
- 登录成功进入工作台，刷新保留会话；错误密码显示真实后端提示。
- 退出后进入登录页，下一位用户登录进入自己的工作台，不带回前一位用户的管理页面。
- 直接访问深层受保护路由，未登录先登录，权限不足显示 403；未知路径显示 404。

## 2. 用户与权限

1. admin 打开「用户与权限」，按用户名 / 姓名 / 邮箱搜索、账户状态筛选并切换分页。
2. 点击「新增用户」，填写唯一用户名、姓名、有效邮箱、角色和至少 12 字符的初始密码，保存后刷新仍可查到。
3. 使用新用户登录，检查实际导航与后端权限。用户详情应显示创建时间、角色与最近登录时间，不返回密码或哈希。
4. admin 修改其姓名、邮箱和角色，新请求按调整后的角色授权；旧 JWT 不能保留撤销权限。
5. 停用用户，旧会话下一次请求应 401；重新启用后需要重新登录，旧令牌不能复活。
6. 重置密码：旧密码及旧 JWT 失效，新密码可登录。重置当前管理员密码后，需要用新密码重新登录。
7. 当前管理员的停用按钮不可用；通过接口尝试停用自身或移除自身 ADMIN，应被拒绝。并发保护至少保留一个有效管理员。
8. lab / student 不能进入用户维护，也不能通过 API 提交用户或全局配置修改。原有三个演示账户在未被人工修改前仍正常登录。

## 3. 系统设置

1. admin 修改系统名称与描述，保存、刷新，侧栏品牌与文档标题同步；登录页通过公开的安全元数据展示名称。
2. 当前版本只读。SMTP 密码、JWT 密钥、数据库密码不得出现在 API JSON 或页面中。
3. 业务时区初始默认 Asia/Shanghai；首次库存业务前可修改，已有库存业务后锁定并显示原因，防止历史日期和月度额度漂移。
4. 配置学年与秋季、春季起止日期，保存后刷新保留。日期必须属于该学年 9 月至次年 8 月，秋季先于春季且不重叠。
5. 打开「数据报表」，默认学期日期应使用保存范围；切换其他学年保留标准边界；自定义起止日期优先，不能被学期设置覆盖。
6. 设置额外通知邮箱，检查与环境收件人、启用采购员邮箱合并。无 SMTP 时明确显示未配置，不能显示投递成功；最近通知结果来自真实记录。
7. 两个管理员同时编辑时，旧 revision 保存应返回冲突提示，重新加载再保存。

## 4. 材料与库存闭环

1. 新建分类与材料，单价 `0.1234`、单位“个”、安全库存 `100`。检查分类层级、删除保护、材料搜索 / 状态 / 分页。
2. 入库 `100`，查看原批次、二维码 PNG、标签和 IN 流水。
3. student 领用 `20`，填写项目、用途、选填课程。余额应为 `80`，领用金额 `2.468`，OUT 流水与中文凭证可查询。
4. admin / lab 归还 `5`，必须进入原批次，余额 `85`；已还 `5`、可还 `15`。累计超原领用量、重复请求、非法数量均不能重复加库。
5. 报废仓库 `3`，填写原因并可选上传图片，余额应为 `82`。检查 SCRAP 流水、操作人、照片鉴权及不可变记录。
6. 预警显示 `82 < 100`。填写备注确认后，补入 `18`，达到 `100` 时自动恢复；再次降低产生新周期。安全库存 0 不预警。
7. 修改档案现价，历史凭证和报表仍使用原单价；归还不冲回月度领用额度，报废不能重复扣已领出材料。

## 5. 工作台与报表

- 工作台显示真实库存价值，按币种分别展示；本月领用、归还、净消耗、TOP10 与按日趋势均从业务数据统计。
- 在仅上述业务的对应统计组中，领用 `20`、归还 `5`、净消耗 `15`，净消耗金额 `1.851`；仓库报废 `3` 单列。若库中有其他记录，汇总应包含它们，不能固定为验收数字。
- 资金占比按领用金额计算，明确标注“未扣归还”；管理员 / 实验员按项目，教师 / 采购员按材料分类，学生只统计本人项目。单位、币种不能随意混合。
- admin / lab 可看个人排行，教师 / 采购员只看授权汇总，student 仅本人领用统计，游客只看公开库存。学生不能看到他人私有项目和个人排行。
- 无数据时呈现空状态，不显示虚构趋势或排名。
- 三种报表各下载 Excel / PDF，合计六种组合。检查中文、日期、金额、单位币种合计、表头冻结与必要分页。跨期归还允许净消耗为负。

## 6. 页面与移动端

- 登录、工作台、材料、库存、入库、领用、归还报废、预警、报表、用户、设置均可操作，不出现“开发中”菜单页。
- 页面标题、按钮、表单、状态标签、圆角、阴影及错误提示一致；手机宽度下无页面横向溢出，抽屉、菜单、筛选和保存按钮可用。
- 网络失败有清楚提示；库存结果未知时仅安全重试原 UUID，不重复扣库 / 加库。
