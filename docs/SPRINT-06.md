## 实施决策

- 保留六类角色与每请求实时授权；密码重置 / 停用递增令牌版本，防止旧会话恢复。用户查询明确投影，不返回密码或哈希。
- 用户维护使用串行管理锁，并在锁内重新校验操作者，保护当前管理员和最后一个有效管理员。
- 全局业务配置使用单行表与 revision 防止覆盖。SMTP / JWT 密钥继续只来自环境变量。
- 业务时区在首次库存业务前允许调整，产生业务后锁定，避免历史统计和自然月额度漂移；业务写入与时区调整协调行锁。学期日期可单独修改，自定义报表日期优先。
- 仪表盘沿用 Sprint 05 的原价格、实际归还日期和精确金额口径，区分币种 / 单位；个人排行仅管理员 / 实验员可见，学生仅本人，游客仅公开库存。
- 复用 CSS Token 与轻量 SVG / HTML 图形，不新增大型图表库。

## 实际完成

- 用户管理：真实 PostgreSQL 搜索、状态筛选与分页；新增、编辑、详情、六角色分配、启停、密码重置、最近登录时间。保留原演示账户，不公开注册。
- 会话安全：BCrypt；停用和密码重置撤销全部旧 JWT，重新启用不复活旧令牌；每次请求从数据库读取角色。保护当前管理员和最后一个有效管理员，包括并发维护。
- 全局设置：名称、描述、业务时区、只读版本、学年和春秋日期、通知收件人持久化；revision 冲突提示；SMTP 准备状态、开关和最近通知结果只读展示。敏感配置仍在后端环境变量。
- 报表默认日期使用配置学期，自定义日期优先；旧学年仍有标准默认范围。
- 工作台：真实库存价值、低库存数量、本月领用 / 归还 / 净消耗 / 报废、TOP10、日趋势、领用资金占比和授权个人排行榜。空数据不造数，数量按单位、金额按币种展示。
- 资金占比使用领用金额，未扣归还。管理员 / 实验员按项目，教师 / 采购员仅按分类，学生按本人项目；个人排行仅管理员 / 实验员可见，游客只见公开库存。
- 全部十个菜单均连接真实页面。沿用既有设计 Token，新增响应式用户卡片、分组设置和轻量图表；长品牌名截断，无横向溢出。
- MIT 许可证、发布前私密文件检查、GitHub CI 配置及 Vercel / Java / PostgreSQL 部署说明已准备；未 Push 或部署。

实际发现并修复：

1. 从设置页退出后，下位用户曾被送回前位管理员路径。区分显式退出与过期恢复；显式退出后新登录进入工作台，过期仍保留合法深链。旧异步身份响应不能恢复已退出用户。
2. Windows Node 24.15 / Vite 进程出现过原生 `0xC0000409` 退出。测试先改为每轮构建后直接 Vite preview API，仍连接真实测试后端；该方式曾完成 64 项，但后续预览也捕获同一原生退出，不能宣称仅切 preview 已根治。该轮仅 14 项通过，后续连接失败如实记录；最终把预览服务切到本机已有 Node 24.22.1 重验。日常演示同样使用较新 Node 与已构建资源。Node 路径只在本机忽略的启动文件 / 进程 PATH 中设置，工程不硬编码本机工具路径。
3. CPU 并发下本地 SMTP 测试夹具 5 秒读取超时；只调整测试夹具为 20 秒，生产 SMTP 超时不变，最终 Maven 全量通过。
4. Windows Java 源启动默认编码导致 E2E 重置脚本中的中文品牌乱码。改为 ASCII Unicode 转义；不修改 Flyway V6。长品牌名的 inline 元素未生效截断，改为可收缩 block，并加入真实浏览器边界断言。
5. 教师 / 采购员资金图按分类统计，避免通过工作台绕过既有项目经费报表权限；前后端同步调整并补断言。
6. 截图修复后的复验为 62 / 64，两项失败分别是启停按钮加载图标改变可访问名称，以及令牌失效测试在移动导航点击前已被背景请求正确跳转。按钮增加稳定 aria-label，提交中显式禁用；测试只替换下一次概览请求的认证头，仍由真实后端返回 401，不伪造响应。后续验证进一步暴露确认弹层在账号启停状态变化后沿用旧开关状态，立即再次点击可能关闭旧弹层；按账号 ID / 状态重新挂载确认组件，避免串用确认状态。先对桌面 / 移动启停各重复三轮，再执行全量，不忽略失败或只提高超时。
7. 新 Node 完整复验为 63 / 64，预览进程保持正常；旧预警测试在活动状态筛选返回前断言全局材料名称，旧列表含历史与活动周期而触发重复定位。补充等待真实筛选响应，并断言筛选后恰好一条，再进入详情；不以 `.first()` 掩盖重复结果。

## 已知限制与后续扩展

业务时区在首次库存业务后锁定；这是保护历史日期与月度额度的一致性约束。JWT 没有刷新令牌或逐设备撤销，普通退出清除当前浏览器会话，停用 / 重置密码撤销所有旧会话。系统设置只管理额外业务收件人，SMTP 连接和密钥仍通过环境变量维护。

沿用前轮边界：通用财务模板未对接学校系统；取消登记可留下未绑定照片；发送中断可能留下 SENDING，需核对后处理；附件需持久卷与备份；单实例方案未压测。生产构建保留 Ant Design vendor 大于 500 kB 的提示，构建成功，尚未进一步按页拆分该依赖。后续可扩展审计、附件清理、真实财务模板和生产初始化，但本轮不继续开发。
