# Sprint 04 人工验收

打开 http://127.0.0.1:5173。密码见本机根 .env 的 DEMO_ADMIN_PASSWORD / DEMO_LAB_PASSWORD / DEMO_STUDENT_PASSWORD，用户名为 admin / lab / student。以下操作真实写入当前库，请使用验收专用材料。

## 1. 入库与管理员限额

1. admin 登录，在材料管理建立材料「领用验收电阻」，单位「个」、单价 0.1234、安全库存 10。
2. 打开材料详情 →「设置领用限额」，设置每人每月 50，保存后应显示 50 个。留空表示不限；填写时必须是正数，最多三位小数。
3. 实验员可以维护普通档案，但无设置限额按钮，后端 PATCH 也会拒绝。修改普通档案不会清空已配置限额。
4. 入库管理创建该材料的两条明细，分别 800 与 100；确认后记录两个 BAT- 批次号。

## 2. 二维码与首次领用

1. 打开 800 个的批次详情，二维码仍可查看 / 下载 / 打印。二维码编码地址不含 JWT。
2. 退出，重新打开该批次地址，应进入登录；用 student 登录后自动返回原批次。
3. 点击醒目的「领用此批次」，应带入材料、规格、批次、库存 800、本月已领 0、剩余额度 50。
4. 输入数量 20，项目编号 LAB-2026-001，用途「模拟电路课程实验」，备注选填。
5. 金额应是 CNY 2.468；点击「核对领用信息」，检查领用人、数量、用途、项目和金额，再点击「确认领用」。
6. 应返回 ISS- 领用单详情，OUT 流水显示 800 → 780 个，完整金额、价格、材料与经办人信息真实保存。
7. 刷新或重新登录，通过「我的领用」找到相同单据；批次余额应为 780，另一批次保持 100，材料总库存 880。

## 3. 额度共享与不足

1. 使用同一个 student 打开第二个批次，应显示本月已领 20、剩余 30。
2. 领用 30 应成功，第二批次余额 70；再次尝试领用 1，应提示月度额度不足，余额不变。
3. 同材料所有批次共享个人额度；其他用户有独立额度。admin 将限额留空保存后，可继续正常领用，之前已领数量仍保留。
4. 在另一个限额不限的材料上尝试数量超过库存，前端提示数量超库存，后端也明确拒绝；零 / 负数 / 超精度请求由自动化测试验证拒绝。
5. 停用 / 归档材料不能领用。零库存批次不出现在手动选择中，批次页显示不可领用。

## 4. 手动领用、历史与权限

1. 「领用管理」→「新建领用单」，输入材料名称或编码搜索，再选择有余额的具体批次。批次多于一页时可加载更多。
2. 历史支持单号 / 材料名称 / 编码 / 项目号搜索、日期范围与服务端分页。没有匹配项应显示空状态；失败时有重试。
3. 手机模拟宽度 390px 时，历史采用卡片，表单与按钮可触控，页面没有横向溢出。
4. admin / lab 可切换「全部领用」，按领用人、项目、材料 / 单号、日期查询。详情展示关联批次与 OUT 流水；具备库存权限时可跳转对应流水页。
5. student / teacher 只能看到本人记录和 PDF。修改 URL 为他人领用单 ID 应返回 403，不应泄露内容；游客、采购员没有领用提交权限。

## 5. 中文 PDF 与快照

1. 详情点击「下载 PDF 凭证」，应下载 ISS-单号.pdf，可用浏览器或 PDF 阅读器打开。
2. A4 页面包含系统名称、单号、本人姓名 / 用户名、材料 / 编码、批次、数量、单位、单价、金额、项目、用途、日期、领用人和经办人手写签字栏。
3. 中文应正常显示且可复制，无方框或乱码；多行长内容会分页，页脚有单号和页码。
4. admin 修改材料当前名称 / 单价后，重新下载旧凭证，材料历史名称与价格、金额仍保持原快照。

## 6. 重试与事务

自动化测试模拟「服务器已提交但浏览器没收到响应」，刷新后安全重试应返回原单，不重复扣库存或额度。真实 PostgreSQL 并发测试验证最后一份库存只有一个请求成功，多批次并发不能绕过限额；末尾流水失败则全部回滚。

开发者运行 `scripts/test-browser.ps1` 会在独立 caizhitong_e2e_test 启动 8081 / 5180，完成真实 API 和浏览器写入测试，不污染日常库。不要把自动写入用例改指向日常数据库。

手机系统相机需能访问 PUBLIC_WEB_URL 指向的前端；默认 127.0.0.1 仅适用于本机，实机需配置局域网 / 公网来源、Vite 监听及必要 CORS。没有本轮的真机扫码、物理打印或电子签名验收声明。

局域网具体配置：根 .env 中 PUBLIC_WEB_URL 使用电脑 IPv4 的 http://地址:5173，CORS_ALLOWED_ORIGINS 加入同一来源；重启后端，在前端目录运行 `npm.cmd run dev -- --host 0.0.0.0`。同网手机访问该地址，允许系统相机扫描标签。HTTP 下也使用浏览器加密随机数生成请求 UUID；需要当前网络允许访问 5173。
