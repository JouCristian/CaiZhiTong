# Sprint 03 人工验收

先启动 PostgreSQL、后端与前端（命令见根 README），打开 http://127.0.0.1:5173。使用根目录 `.env` 中 DEMO_ADMIN_PASSWORD / DEMO_LAB_PASSWORD / DEMO_STUDENT_PASSWORD 对应的本机凭据。以下操作会真实写入当前库，请使用验收专用材料。

1. **准备档案**：admin 登录，在材料管理建立「入库验收」类目，创建电阻、电容两份启用档案。单位「个」、单价「0.1234」、安全库存 10。材料列表显示真实零库存，详情的批次数为 0。
2. **多材料入库**：打开「入库管理」→「新建入库单」。第一行选择电阻、数量 2.125、库位 A-01；点击「添加材料明细」，选择电容、数量 3.875。默认带出档案价格，可改入库价、填有效期及备注。汇总金额应为 CNY 0.7404。数量必须大于零，材料必选。
3. **提交与持久化**：确认入库后提示成功并打开详情。应生成 IN- 单号，两条明细各有 BAT- 批次号与经办人。刷新后按单号搜索，仍能打开相同单据。已提交单据没有编辑 / 删除 / 撤销按钮。
4. **库存汇总**：打开库存管理，按电阻名称或编码搜索，当前库存 2.125 个、1 个批次。点击材料，抽屉显示批次价格、时间、库位、有效期及关联单号。再次入库该电阻 1.875 个，刷新库存后应为 4 个、2 个批次。
5. **筛选与分页**：依次选择分类、零库存 / 低库存 / 库存充足。搜索不存在的名称应显示空状态。每页数量和页码由服务端查询；有足够材料时切换下一页验证不同记录。
6. **流水追溯**：库存管理切到「库存流水」。按材料名称 / 编码、批次、类型 IN 与日期范围查询。每条新批次流水是 0 → 本次入库数量；交易编号唯一、经办人正确。点击关联单据打开入库详情，点击批次进入批次页。
7. **价格快照**：材料管理修改电阻当前单价，再打开旧入库单 / 批次，旧价格、金额应保持原样。已有批次后尝试修改计量单位，应得到清晰拒绝提示。
8. **二维码**：批次详情点击「二维码标签」，预览含材料名、规格、批次号、真实二维码。下载 PNG 可打开；点击打印出现浏览器打印窗口，仅打印标签。无需专用打印机。
9. **扫码路由**：同一浏览器打开二维码指向的 `/stock/batches/BAT-…`，已登录能查看；复制地址后退出，再访问应跳转登录，成功后返回原批次。不存在的批次显示明确提示。手机需另行配置可达地址，127.0.0.1 不能指向电脑。
10. **权限**：lab 可入库、查询、打印，仍不能维护用户 / 管理员配置。student 没有入库菜单，直接 `/inbound` 为 403 页面，但材料详情能看真实库存和批次。后端禁止学生 POST（自动化测试覆盖）。
11. **错误与重试**：在测试库环境模拟提交后网络响应丢失，页面提示「安全重试原请求」，刷新后重新打开新建入库仍保留该请求。重试返回原单据，库存不重复增加。普通用户可在临时断开后端时验证列表错误提示与重试。
12. **工作台**：应显示真实档案数、有库存材料种数、低库存种数和最近入库记录；待处理申请保持 0，领用、归还、报表仍是开发中。
