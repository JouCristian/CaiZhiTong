## 登录与恢复

1. 未登录直接访问 `/materials`，应进入登录页。
2. 留空点击「登录工作空间」，应显示用户名和密码校验提示。
3. 使用 admin 与错误密码，应显示「用户名或密码错误」，按钮恢复可用。
4. 使用正确凭据登录，应回到原先请求的材料管理页，显示材料列表。
5. 点击左上品牌进入工作台，确认当前用户为系统管理员，材料档案数为真实数量，其余三项为 0，最近动态没有记录。
6. 刷新浏览器，身份与当前页面应恢复，不要求重新输入密码。

1. 登录后在开发者工具 Application / Session Storage 中将 `caizhitong.session` 改成无效字符串，再刷新，应返回登录并提示过期。
2. 登录后停止后端并刷新，应显示无法恢复登录与「重新连接」；重新启动后点击该按钮应恢复，不丢失尚未过期的会话。

4. 登录失败应恢复提交按钮；网络断开或请求超时应显示明确错误。

## Sprint 02 · 材料分类与档案验收

Sprint 01 已由用户验收通过。以下检查使用当前 Sprint 02；登录、权限、布局等回归步骤仍适用。

### 1. 分类维护

1. 使用 admin 登录，进入「材料管理 → 类目管理」。
2. 点击「新增类目」，名称填「电子元器件」、父级留空、排序填 10，保存。应出现真实大类，刷新仍存在。
3. 选中该大类，点击「新增子类」，名称填「精密电阻」，保存。展开树应看到父子关系。
4. 编辑子类描述及排序，保存后右侧详情立即更新。
5. 同一父级下重复创建同名分类，应显示明确冲突提示。
6. 已有子类的大类不能删除。选择一个没有子类、没有材料的临时类目，删除并刷新，应不再出现。
7. 父级选择仅提供合法大类；后端会继续拦截自引用、循环移动和超过两层的基础分类。品牌、型号不在这里重复建立。

### 2. 材料新增、详情与编辑

1. 切换「材料档案」，点击「新增材料」。
2. 填写名称「金属膜电阻 10kΩ」、所属子类「精密电阻」、品牌「国巨」、型号「MFR-25」、规格「10kΩ，±1%，0.25W」、单位「个」、单价「0.1234」、币种 CNY、安全库存 100，保存。
3. 应提示保存成功，列表立即出现档案与 MAT- 开头的十位流水编码，当前库存为「未入库」。
4. 打开详情，核对 ID、编码、完整分类、品牌、型号、规格、单位、精确单价、币种、安全库存、备注与两个时间字段。
5. 编辑名称、规格、单价和备注，保存后列表更新，材料编码不变。
6. 刷新页面，通过编码再次查询，确认修改已真实保存。
7. 必填字段留空不能提交。单价与安全库存不可为负，单价最多四位小数；对应后端非法请求也由自动测试确认拒绝。

### 3. 搜索、筛选与分页

1. 名称输入框输入部分名称，应自动查询；输入完整编码，应准确找到该档案。
2. 使用左侧分类树筛选大类 / 子类；点击「展开」，查看由真实材料属性生成的品牌与型号节点。
3. 依次使用品牌、状态筛选，并改变创建时间排序，观察列表与数量随查询结果更新。
4. 输入不存在的名称，应显示精美空状态；点击「清除筛选」恢复列表。
5. 如需更多材料，可在根目录执行 ` .\scripts\seed-demo.ps1 ` 导入十份开发演示档案。它不会创建库存。
6. 有超过十份档案后，将每页数量改为 10，点击下一页，确认材料不同，筛选或排序变化后回到第一页。
7. 开发者工具 Network 可看到真实 GET /api/materials 的 keyword、categoryId、brand、status、page、size、order 参数。

### 4. 状态、归档与分类保护

1. 点击某条材料的「停用」，列表状态立即变化；选择「停用」筛选能查到该档案。
2. 再次启用，状态恢复。管理员点击「归档」并确认，档案仍存在且状态为「已归档」。
3. 归档档案可查看详情，不再显示编辑 / 启停按钮，本轮不支持恢复归档。
4. 回到其所属分类，删除按钮应受保护。关联归档材料也不能删除类目。
5. 工作台的材料档案数来自真实数据库；库存、待处理申请和预警仍为 0，流转动态为空。

### 5. 角色与异常

1. lab 可新增、编辑、启停材料，但不能归档或维护分类。
2. student 可查看和筛选材料，不能看到新增、编辑、归档及分类维护按钮。
3. 后端真实 403 拦截已由集成 / HTTP / 浏览器测试验证，不仅依赖按钮隐藏。
4. 已登录时临时停止后端，点击材料列表刷新，应显示加载失败与重试；重启后可重新加载。
5. 手机模拟宽度 390px，表单、类目详情、抽屉应可操作；材料表格支持横向滚动，页面本身不横向溢出。
