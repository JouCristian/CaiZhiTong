## 本地隔离环境

运行 `scripts/test-browser.ps1 -OAuthMock` 会构建前端、启动独立测试后端和回环 Mock Provider，执行桌面 / 手机流程后关闭测试服务。测试库 `caizhitong_v070_demo_e2e_test` 与日常库、生产库独立；不得将测试账号或 Mock 配置用于生产。

1. 打开登录页，GitHub 为主按钮，账号密码可展开。原管理员密码登录后仍进入原业务工作台，材料、入库、领用、归还报废、报表、用户和设置正常。
2. 合成 GitHub 身份首次授权后默认进入演示工作台，仅有 GUEST；账户菜单显示昵称，头像加载失败时显示姓名回退。
3. 演示工作台显示“公开演示 · 只读”、25 种材料、50 个批次、5 种低库存及5种零库存，CNY / USD 分开显示。
4. 演示材料按名称 / 编码 / 型号搜索，分类筛选与分页正常；搜索正式哨兵名称应为空。演示库存可筛选正常 / 低 / 零库存。
5. 查看材料详情及两个批次，点击“示例变化”看到合成入库和消耗，不出现真实人员、真实单据、私人照片或任何写入按钮。
6. 使用该 JWT 直接调用正式材料、库存、summary、批次详情 / 二维码、正式工作台、用户、附件、报表 / 导出和任何写入 API，应返回 403。匿名调用 Demo API 为 401。
7. 管理员将该用户改为 STUDENT，同一 JWT 的下一正式材料请求成功；管理员管理入口仍拒绝。改回 GUEST，下一正式业务请求立即 403。刷新 / 聚焦页面后导航与当前角色同步。
8. 同一合成数字 ID 再次授权仍是原账户；改变 GitHub handle / 头像不新建账户。停用后原 JWT 和再次登录均失败。
9. 取消授权、上游失败、伪造 state、交换码过期 / 重放 / 错误 verifier 均显示安全错误；地址栏不出现 JWT，成功后移除短期 fragment。
10. 手机打开导航、筛选材料、查看批次及退出，布局可操作；退出后刷新不恢复会话。
